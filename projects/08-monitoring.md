# Project 8 — Monitoring

## Goal

Make the final app observable enough to answer basic operational questions.

## Build

- Run Prometheus and Grafana.
- Collect host/container CPU and memory metrics.
- Expose or collect application request rate, error rate, and latency metrics.
- Create one Grafana dashboard with meaningful labels/time range.
- Create a basic alert (for example, sustained error rate) and a short response note.
- Keep application logs searchable and free of secrets.

## Acceptance test

Generate a controlled error, find the relevant metric/dashboard and log, and explain the diagnosis path. Show how a healthy request differs from a failing one.

## Portfolio finish

Create a top-level project README with architecture, local/cloud instructions, screenshots/redacted evidence, cost cleanup, security notes, and known limitations.
