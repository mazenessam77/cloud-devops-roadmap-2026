# Job-ready checklist

Start applying when you can demonstrate most of this. Do not wait to complete every optional topic.

- [ ] Navigate Linux, permissions, processes, logs, and services confidently.
- [ ] Troubleshoot a basic Linux service using `systemctl`, `journalctl`, `ss`, and logs.
- [ ] Explain IP addresses, DNS, TCP, ports, HTTP, and a request path.
- [ ] Clone, branch, commit, push, and open a pull request with Git.
- [ ] Write a small Bash script and read simple Python or Go.
- [ ] Explain REST, a health endpoint, environment variables, and basic auth versus authorization.
- [ ] Query a simple PostgreSQL database and explain connections, backups, and indexes.
- [ ] Use one cloud provider: VM, network, IAM, load balancer, object storage, database, logs.
- [ ] Build images and run a multi-service app with Docker Compose.
- [ ] Create a GitHub Actions workflow that tests, builds, and deploys.
- [ ] Use Terraform to plan, apply, and safely describe state.
- [ ] Explain Pod, Deployment, Service, Ingress, ConfigMap, Secret, probes, and requests/limits.
- [ ] Read logs and use a basic Grafana dashboard and alert.
- [ ] Explain your projects: architecture, trade-offs, a failure you diagnosed, and how credentials are protected.

## Interview practice

Prepare a three-minute walkthrough of one project: request path, deployment route, observability, and one problem you fixed. Be honest about what you built yourself.
