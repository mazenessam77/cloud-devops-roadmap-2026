# Cloud & DevOps Roadmap — 2026

A practical path from zero to a first Cloud Engineer, DevOps Engineer, or Cloud Operations Engineer role. The goal is not to collect tools: it is to understand how an application moves from code to a running, observable service.

> **Learn the fundamentals first, understand how applications work, then learn how to deploy, automate, monitor, and operate them.**

Start with [HOW-TO-FOLLOW-THE-ROADMAP.md](HOW-TO-FOLLOW-THE-ROADMAP.md), then use [ROADMAP.md](ROADMAP.md) as your visual path. Read [prerequisites.md](prerequisites.md) only for the small amount of application and database background that makes deployment clearer; it is not a separate career track. Work through the numbered [docs](docs/), then complete the [projects](projects/). You do not need a CS degree, backend career, network-engineering background, or Linux-admin job to begin.

## Recommended learning rule

**One cloud provider + Linux + networking + Git + Bash + one programming language + Docker + one CI/CD tool + Terraform + Kubernetes + Prometheus/Grafana** is enough for the main path. Use Python as the default language and GitHub Actions as the default CI/CD tool. Pick **one** cloud—AWS is used for examples here.

## Outcome

You will be able to explain and operate this chain:

`Code → process → port → API → database → container → server → cloud → CI/CD → IaC → Kubernetes → monitoring`

See the [job-ready checklist](job-ready-checklist.md) before applying; optional advanced topics are deliberately deferred.
