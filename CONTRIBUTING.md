# Contributing

Contributions that keep this roadmap practical, accurate, and beginner-friendly are welcome.

## Good first contributions

- Fix a typo, broken link, or unclear explanation.
- Improve a lab, command example, README, or diagram.
- Add a reproducible troubleshooting note or small CI/script improvement.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Make one small, clear change.
4. Check links, Markdown rendering, and commands where possible.
5. Open a Pull Request explaining what changed and how you checked it.

Please avoid adding advanced tools or changing the beginner-first roadmap order without first opening an issue to discuss it.
